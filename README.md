## Español

Esta es mi página de portafolio personal. La hice desde cero con HTML, CSS y JavaScript, sin frameworks, para tener algo simple, rápido y completamente mío.

- `style.css` — todo el diseño, colores y animaciones
- `script.js` — la animación al hacer scroll y la navegación suave entre secciones, organizado en clases

No hay build ni dependencias que instalar. Clonas el repo, abres `index.html` y ya está funcionando.
